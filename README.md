# Eliyte™ Araştırma Merkezi

Official website for Eliyte™ Araştırma Merkezi - A leading multidisciplinary research institution advancing digital technologies, artificial intelligence, IoT, energy systems, finance, mathematics, and emerging scientific fields.

## 🚀 Features

- **Modern Glass Effect Design**: Beautiful glass morphism UI with dark purple theme
- **Multi-page Application**: Complete navigation with React Router
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Production Ready**: Optimized build configuration for deployment
- **Comprehensive Content**: 8 complete pages with detailed information

## 📄 Pages

- **Home**: Hero section with key highlights and featured research areas
- **About Us**: Mission, vision, core values, and approach
- **Research Areas**: 10+ research domains with detailed descriptions
- **Solutions & Services**: Comprehensive service offerings and process
- **Partners & Collaborations**: Partnership opportunities and collaboration areas
- **News & Publications**: Latest research updates and publications
- **Careers**: Open positions and company culture
- **Contact**: Contact information and inquiry guidelines

## 🛠️ Tech Stack

- **React 19**: Modern React with hooks
- **Vite**: Fast build tool and dev server
- **React Router v7**: Client-side routing
- **CSS3**: Custom styling with glass effects and animations

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deployment

The project is production-ready and can be deployed to:
- Vercel
- Netlify
- GitHub Pages
- Any static hosting service

Simply run `npm run build` and deploy the `dist` folder.
